# Repository contents and provenance

This public package is a curated reproducibility snapshot of the multi-climate experiment underlying the manuscript. It is intentionally not a dump of every exploratory file generated during development.

## Included

- Exact multi-climate core used by the final development pipeline.
- Weather acquisition/audit script plus raw and processed weather products.
- Frozen temporal protocol and training specification.
- Horizon-selection script and summary outputs.
- Final PPO training script and all ten frozen final PPO checkpoints.
- Fully irrigated development and held-out reference libraries.
- Frozen held-out evaluation manifest and complete final controller outputs.
- Confirmatory Friedman and Wilcoxon-Holm analysis code and outputs.
- Climate, water-allocation, latency, and PPO seed-robustness diagnostics.
- PPO action-projection diagnostic code and manuscript-level summary outputs.
- Restricted offline perfect-foresight numerical-reference code and outputs.
- Robust descriptive water-productivity analysis.
- Publication figure-generation script and final portrait figures.
- Current manuscript source/PDF for traceability.

## Intentionally omitted

- Obsolete Tunis-only PPO development versions and superseded exploratory scripts.
- Hyperparameter-search databases and intermediate models that did not define the final reported controller.
- Horizon-selection checkpoint ZIP files; they can be regenerated by `select_ppo_training_horizon.py` and are not required to evaluate the frozen final PPO models.
- Two large step-level projection CSV intermediates (~59 MB combined); they are regenerated by `55A`/`55B`. Their manuscript-level summaries are included.

The omissions reduce repository clutter and size without removing the code, frozen final checkpoints, final observations, statistical outputs, or compact diagnostic results needed to inspect the published findings.
